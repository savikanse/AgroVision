
# AgroVision — AI-Powered Plant Disease Detection

AgroVision is a deep learning-based plant disease detection system that uses **MobileNetV2 transfer learning** and computer vision to classify plant leaf images into **38 plant/disease classes** using the **PlantVillage dataset**. The model achieves **95.46% validation accuracy** and is deployed through a Streamlit interface for interactive crop health assessment.

## Features

- 🌱 Plant disease classification from leaf images
- 🧠 MobileNetV2 transfer learning
- 🔬 Computer vision and image classification
- 📊 38-class PlantVillage dataset
- ⚙️ Image preprocessing and augmentation
- 🚀 Real-time predictions using Streamlit
- 📈 95.46% validation accuracy

## Tech Stack

- Python
- TensorFlow
- Keras
- MobileNetV2
- NumPy
- Streamlit

[You can download the dataset from Kaggle](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)


Once the dependencies and trained model are set up, run 'streamlit run app.py' . The application will start locally.
